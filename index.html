Cloudflare R2 Direct Storage Setup (3 Steps)
🎁 100% Free 10 GB Storage & Zero Egress Fees:

Cloudflare R2 provides 10 GB of free object storage every month with 0 egress bandwidth fees. You only set this up once, and it syncs to all your devices automatically via Supabase!

Step 1: Create an R2 Bucket in Cloudflare
  1. Log in to dash.cloudflare.com.
  2. In the left sidebar, click Storage & Databases > R2.
  3. Click Create Bucket > Name it (e.g., livepos-photos) > Click Create Bucket.
  4. In your new bucket, go to Settings > Public Access > click Allow Access (R2.dev subdomain) or connect a custom domain so photos can be viewed in invoices.
Step 2: Add CORS Policy to Bucket

In bucket Settings > CORS Policy > click Add CORS Policy and paste this JSON rule: 

[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "MaxAgeSeconds": 3600
  }
]
Step 3: Create R2 API Token
  1. In Cloudflare R2 Overview, click Manage R2 API Tokens (top right).
  2. Click Create API token.
  3. Permissions: Select Object Read & Write.
  4. Bucket: Select Specify bucket > choose your bucket (or all buckets).
  5. Click Create API Token.
  6. Copy your Account ID, Access Key ID, and Secret Access Key into this app's Cloud Settings!
Configure once & syncs across all devices!
