Google Cloud Console Setup (3 Steps)
Free & Personal Account Compatible: Works with any standard free 15 GB personal @gmail.com account. No paid Google Workspace required!
Step 1: Open Google Cloud Console & Enable Google Drive API
  1. Go to console.cloud.google.com and sign in with your Gmail.
  2. Create a new project (e.g. name it LiveSelling-POS).
  3. In the search bar at the top, type "Google Drive API" and click Enable.
Step 2: Configure OAuth Consent Screen
  1. Go to APIs & Services > OAuth consent screen.
  2. Select User Type: External > Click Create.
  3. Enter App name: LivePOS Photo Archive and your email for support.
  4. Under Scopes, add .../auth/drive.file.
  5. Under Test users, add your personal Gmail address.
Step 3: Create OAuth Client ID (Web Application)
  1. Go to APIs & Services > Credentials > Click Create Credentials > OAuth client ID.
  2. Application type: Web application.
  3. Under Authorized JavaScript origins, add:
    {{ currentAppOrigin }}
  4. Click Create and copy your Client ID (ends in .apps.googleusercontent.com).
  5. Paste it into the Google OAuth Client ID input box in this app's Cloud Settings!
